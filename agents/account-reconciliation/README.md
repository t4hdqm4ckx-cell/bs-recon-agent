# Account Reconciliation Agent
**Status:** Operational (v0.1.0)

Reconciles all BS accounts on BD1–BD3 per `skills/bs-reconciliation/SKILL.md`. Produces 6-tab workpapers (Summary, Detail, Supporting, Exceptions, Proposed JEs, Audit Trail) and an MD memo per account. Output naming: `YYYY-MM_<entity>_<account>_<name>_Rec_v<n>.xlsx`.

**First run:** Nov 2026 close — see `workpapers/2026-11/` and `outputs/2026-11/2026-11_package_envelope.json`.
